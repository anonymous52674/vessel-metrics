# Sensitivity, Redundancy, and Ranking Agreement of 20 Metrics for 2D Blood Vessel Segmentation

Code for calculating the 20 segmentation metrics evaluated in the paper. The metrics are compared in three experiments:

1. **Human annotators** (`run_human_annotators.py`): agreement between two manual annotations of the same image.
2. **Synthetic perturbations** (`run_noise.py`): ground truth masks compared with perturbed versions of themselves.
3. **Segmentation methods** (`run_models.py`): predictions of trained models compared with the ground truth.

The code used for training the segmentation methods and generating their predictions is in the [`training`](training) folder, which has its own [README](training/README.md) and dependencies.


## Installation

Python 3.10 or later is required.

```bash
pip install -r requirements.txt
```

The code was tested with Python 3.13, numpy 2.4, scipy 1.17, scikit-image 0.26, scikit-learn 1.8, networkx 3.6, opencv 4.13 and pillow 12.1.

## Data

All scripts read the data from the `data` folder by default. The datasets used in the paper must be downloaded from their original sources.


## Running

```bash
python run_human_annotators.py
python run_noise.py
python run_models.py
```

The results are saved in `results/human_annotators.csv`, `results/noise.csv` and
`results/models.csv`. Use `--datasets` to process only some of the datasets.

`run_models.py` expects the predictions generated by the [`training`](training) code, organized as `data/predictions/<dataset>/<method>/<image>.npz`.
